# Exercises

Exercises are focused tasks for checking one skill. They are smaller than projects and may be completed before the related multi-tool build.

| Area | Exercise | Prepare with |
|---|---|---|
| SQL | [SQL practice questions](sql/sql-practice-questions.md) | [Core SQL](../notes/03-sql-and-databases/core-sql.md) |
| Kafka | [Producer and consumer lab](kafka/producer-consumer-lab.md) | [Kafka introduction](../notes/08-apache-kafka/01-apache-kafka-introduction.md) |
| Linux | [Server administration assignment](assignments/linux-server-administration.md) | Basic Linux and SSH familiarity |

> **Security warning:** the historical Linux assignment contains a hard-coded public server address and credentials. Treat them as compromised, do not attempt to use them, and wait for an instructor to provide a safe lab environment.

When you can explain your result and rerun it from a clean environment, continue to the [project index](../projects/README.md).
